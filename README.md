# cortico-world-casino · 月下牌桌

一张只存在于这台电脑里的 21 点(Blackjack)牌桌:**AI 与主人对坐对打**,开局选庄——你坐庄,
或让 AI 坐庄;庄闲各管一个筹码池,赢的人从对家池里拿钱。筹码是游戏内数字,不涉及真实货币。

## 玩法(v0.2.0 对战版)

1. **选庄**:面板上点「我坐庄」或「让 AI 坐庄」。庄家收注与赔付,闲家下注。
2. **下注**:闲家押注(在最小注与单手上限之间,且不超过双方余额的较小值——庄家赔得起才收)。
3. **发牌**:闲家两张明牌,庄家一亮一暗。
4. **闲家行动**:要牌 / 停牌 / 首两张加倍(翻倍后仍需双方赔得起)。爆牌立即输。
5. **庄家行动**:暗牌亮开,**自由决定**要牌还是停牌(看得到闲家的点数——这是坐庄的收益);
   没有赌场那种强制 17 停。庄爆即闲赢。
6. **结算**:比点数,大者赢;平局退注;闲家黑杰克赢 1.5 倍,庄家黑杰克闲家输注。
7. **破产**:余额低于最小注可领救济金(重置起始筹码,记破产次数)。AI 走 `casino_bank`,
   玩家走面板按钮。

每手结束回到待开局,角色不变;想换庄,再点一次选庄按钮。

## AI 怎么参与

- 轮到它时收到 `casino.turn` 事件(下注,或做庄决定),用 `casino_player` / `casino_dealer` 行动;
  每手结算推 `casino.result`。AI 不开局、不抢跑——什么时候有下一手由主人决定。
- `casino_table` 看桌面状态与历史,`casino_bank` 查账户/领救济。
- 面板上等 AI 的时候有「催一下」按钮:重发一次 turn 事件。

## 面板

绿呢桌面布局:庄家席在上、闲家席在下、押注居中;CSS 扑克牌面(暗牌为蓝纹牌背);
筹码与战绩挂在座位边;按钮按牌局阶段自动启用/禁用;结算横幅带彩色徽章;底部可折叠历史。

## 配置(worlds.casino)

| 键 | 默认 | 含义 |
|---|---|---|
| `enabled` | false | 挂载这张桌 |
| `startChips` | 1000 | 首次开局与救济金发放的筹码数 |
| `minBet` | 10 | 最小下注;低于它的余额视为破产 |
| `maxBet` | 200 | 单手最大下注 |

存档在部署数据目录的 `casino-table.json`,每次落子后原子写;删掉它就是一张全新的桌。

## 安装

WebUI「扩展」页安装 `cortico-world-casino`,或把本包目录用 `file:` 协议加进
`extensions/package.json` 后重启进程。启用:`worlds.casino.enabled: true`。

## 简化说明

一副 52 张牌靴,耗尽重洗;没有分牌(split)、保险与弃牌。庄闲的自由行动制不是赌场规则,
是这张桌自己的规矩。
